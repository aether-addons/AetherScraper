# Help

Open AetherScraper Tools from Kodi Program add-ons.

Use **Settings** to configure the module. Use **Providers** to review provider state. Provider group actions ask for confirmation before changing settings.

For Umbrella/FenLight, enable external providers/scrapers in the host add-on, then select AetherScraper where supported. Use the companion selector URL:

```text
plugin://plugin.program.aetherscraper/?action=MediaPlay
```
